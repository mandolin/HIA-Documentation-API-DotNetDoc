## Contents

The reference covers public bindings from `@hia-doc/dotnet-source-extractor`, `@hia-doc/dotnet-xml-doc-extractor`, `@hia-doc/dotnetdoc-adapter`, `@hia-doc/dotnetdoc-producer`, `@hia-doc/dotnetdoc-runner` and `@hia-doc/dotnetdoc-spec`. It preserves runtime documentation and declaration-file types, bilingual fields, signatures, original source maps, sixteen current/legacy JSON schema exports, static declaration data and authorized complete sources.

## Publication

`snapshot.json` pins the source commit, production registry, publication identity and complete archive digests. GitHub Actions verifies archived files, native fields, scoped bindings, original declaration exports, source ownership, maps and full-source downloads before deployment. Generated content is supplied through a fixed release archive.

To update the site, build the source repository, validate both locales, publish the fixed archive and report, and update the snapshot. Version and language targets select this DotNetDoc partition.

## Command reference

The generated reference includes `hia-dotnetdoc` and its `dotnetdoc` alias, with their shared implementation and explicit invocation identities. It provides localized usage, package and version identities, defaults, examples, exit results, static pages and authorized declaration-source links. Native descriptions, parser observations and original HIA documents remain available under `commands/` beside the independent website projection. Source positions are declaration-line anchors.
